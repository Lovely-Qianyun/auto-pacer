# auto-pacer

> 本仓库仅作学习与个人使用，分发或商用前请自行评估相关条款与风险。


一个增加微信运动 / 支付宝运动步数的小工具。

运行一次，它会在设定范围内随机生成一个步数，写入你的 Zepp Life（原"小米运动"App）运动账号，只要该账号已在 App 内关联微信运动、支付宝运动，两边的步数就会跟着更新。

- 纯本地运行：账号密码只保存在**你自己的电脑**上，不经过任何服务器中转
- 不做定时、不推送消息，跑一次刷一次

> 本工具生成的是非真实行走记录，仅用于你自己的运动数据，请自行决定使用方式。

## 快速开始

需要 **Python 3.10+**（终端执行 `python --version` 检查）和一个 **Zepp Life 账号**（手机号或邮箱注册即可，注意不是小米账号）。

```powershell
# 1. 安装依赖
python -m pip install requests pytz pycryptodome
```

## 配置（首次使用）

账号密码保存在**用户主目录**下的 `.auto-pacer.json`（Windows 路径即 `%USERPROFILE%\.auto-pacer.json`）。文件不存在时直接新建：

```json
{
  "user": "13888888888",
  "pwd": "your_password",
  "min_step": 18000,
  "max_step": 25000
}
```

| 字段 | 默认 | 说明 |
|---|---|---|
| `user` | 必填 | 登录账号：手机号（自动补 +86）或邮箱 |
| `pwd` | 必填 | 登录密码 |
| `min_step` / `max_step` | `18000` / `25000` | 随机步数范围；想刷固定值就把两者设成同一个数 |

`user`/`pwd`/`min_step`/`max_step` 之外的字段（令牌缓存等）由程序自动维护，**不要手改**。

保存后运行：

```powershell
python main.py
```

输出出现 `提交结果: success` 与 `执行完成: 成功` 即完成。退出码 `0` = 成功，`1` = 失败。

改步数目标就是改文件：编辑主目录 `.auto-pacer.json` 里的 `min_step`/`max_step`（想要固定值就把两个设成同一个数），保存后直接运行。想回到"默认随机"就删除这两个字段，程序会用 18000 ~ 25000。程序不读取任何环境变量。

只想检查配置/环境是否就绪、不发请求：

```powershell
python main.py --dry-run
```

## 换新电脑 / 备份

账号密码与登录缓存只在 `~/.auto-pacer.json` 这一个文件里，因此：

- **整个文件夹拷到新电脑**：装依赖后，把主目录的 `.auto-pacer.json` 一起带过去即可
- 项目目录内**没有任何敏感文件**，可以放心用Git管理代码
- 多台电脑共用同一配置：直接把该文件复制过去即可（路径固定为用户主目录）

## 步数没变 / 报错

| 现象 | 处理 |
|---|---|
| 微信/支付宝从不更新 | 先在 Zepp Life App 里关联微信运动、支付宝运动（"我的 → 账户设置"附近），否则永远不会同步 |
| 新注册账号同步被拦截 | 从未绑过手环的账号会被平台拦截。本项目内置虚拟设备，首次提交成功后自动登记，跑一次即可；仍不行就绑定一个真实手环再跑 |
| 支付宝长期不更新 | App 内：注销账号 → 清空数据 → 重新登录 → 重新关联支付宝 |
| Zepp Life 里看不到新步数 | 正常。刷入值只同步给已关联的第三方，App 本身不显示 |
| `429` | 请求过频被限流，稍后再试 |
| 登录失败 | 令牌失效会自动回退到账号密码重新登录；仍失败则核对 `~/.auto-pacer.json` 里的账号密码 |

更完整的排查表（面向智能体使用）见 `references/troubleshooting.md`；实现原理见 `references/architecture.md`。

## 安全

- `~/.auto-pacer.json`，内含账号密码 + 令牌，是唯一的敏感文件，勿外传、勿提交、勿分享
- 令牌与账号密码同文件明文保存，本地文件即信任边界
- 运行时账号自动脱敏显示（如 `138****8888`），不会出现完整账号与密码
