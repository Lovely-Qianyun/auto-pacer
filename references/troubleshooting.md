# 故障排查

| 现象 | 处理 |
|---|---|
| 登录失败 / 密码错误 | 令牌失效会自动降级到账号密码登录；仍失败 → 核对 `~/.auto-pacer.json` 中 `user`/`pwd`。改过密码通常无需删文件：旧令牌校验不过会自然落到全量登录并写回新令牌 |
| 提示"未配置账号" | 配置不在本目录：检查主目录（`$env:USERPROFILE`）下 `.auto-pacer.json` 是否存在、`user`/`pwd` 是否齐全；或按向导流程配置 |
| 配置文件无法解析 | main.py 会自动把损坏文件改名 `.corrupt` 备份并重建；恢复时对照备份内容补 `user`/`pwd` |
| 提交成功但微信/支付宝不更新 | 平台只把步数同步给**已关联的第三方**：需在 Zepp Life App 中关联微信运动/支付宝运动。从未绑过手环的新账号会被拦截：首次提交使用内置虚拟设备，成功后平台自动登记（可再跑一次）；仍不行则绑定一个真实手环 |
| 支付宝不更新 | Zepp Life → 设置 → 账号 → 注销账号 → 清空数据 → 重新登录并重新绑定第三方 |
| 429 / 网络错误 | 平台限流，稍后重试（建议间隔几分钟以上） |
| 账号正常但步数没变化 | Zepp Life 本身不显示刷入值，只有关联的第三方会同步（正常现象） |
| 想换账号 | 直接改 `~/.auto-pacer.json` 的 `user`/`pwd`，并删除其中 `access_token`/`login_token`/`app_token`/`user_id` 字段后重跑（强制全量登录） |
